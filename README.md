## 🇬🇧 English

**Marvel Snap Turbo** is a powerful automation and collection management tool for Marvel Snap players. It helps you automate daily rewards, monitor shop bundles, and easily share your card collection with friends!

### ✨ Key Features
- **🚀 Auto-Claim Rewards**: Automatically logs in and claims your daily free credits.
- **🛒 Shop Bundle Alerts**: Smart 8-day filter for web shop bundles with Discord image notifications.
- **📊 Collection Gallery**: Syncs local game data and generates a neat, beautifully sorted HTML card gallery (Sorted by Cost, then Power).
- **📤 Share Code System**: Generate and import share codes to view your friends' card collections instantly.
- **🌐 Bilingual Support**: Seamlessly switch between English and Traditional Chinese in one click.

## 🇭🇰 繁體中文

**Marvel Snap Turbo** 是一款專為《Marvel Snap (漫威快攻)》玩家打造的自動化與收藏管理工具。它可以幫你自動領取每日獎勵、監控網頁商店禮包，還能一鍵生成精美的卡片展覽館與好友分享！

### ✨ 核心功能
- **🚀 自動領取獎勵**：自動登入網頁並領取每日免費 100 點數。
- **🛒 禮包商店通知**：具備 8 天智慧過濾機制，自動將新禮包截圖並發送至 Discord。
- **📊 卡片收藏展覽**：同步本地遊戲數據，自動生成並排序卡片展覽館（依 Cost 優先、Power 次之雙重排序）。
- **📤 快速分享與導入**：一鍵生成專屬卡片庫代碼，或貼上好友的代碼即時檢視對方的收藏。
- **🌐 雙語介面切換**：支援英文與繁體中文介面一鍵切換。
