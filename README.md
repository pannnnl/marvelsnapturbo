## 🇬🇧 English

**Marvel Snap Turbo** is a powerful automation and collection management tool for Marvel Snap players. It helps you automate daily rewards, monitor shop bundles, and easily share your card collection with friends!

### ✨ Key Features
- **🚀 Auto-Claim Rewards**: Automatically logs in and claims your daily free credits.
- **🛒 Shop Bundle Alerts**: Smart 8-day filter for web shop bundles with Discord image notifications.
- **📊 Collection Gallery**: Syncs local game data and generates a neat, beautifully sorted HTML card gallery (Sorted by Cost, then Power).
- **📤 Share Code System**: Generate and import share codes to view your friends' card collections instantly.
- **🌐 Bilingual Support**: Seamlessly switch between English and Traditional Chinese in one click.

### 📖 How to Setup Discord Notifications
If you want to receive Discord alerts for daily reward claims and new shop bundles:
1. Click **[Invite MS Daily Store Alert Bot](https://discord.com/oauth2/authorize?client_id=1560327479711764603&permissions=117760&integration_type=0&scope=bot)** to add the bot to your Discord server.
2. In any text channel on your server, type `!id`.
3. The bot will send you a Direct Message (DM) containing your **Discord User ID**.
4. Copy and paste your User ID into the application field.

### 🔒 Privacy & Data Safety
- **Zero Login Data Stored**: This program **does NOT** steal, collect, or store any of your login credentials or personal accounts.
- **Local Read-Only**: It only reads your local Marvel Snap JSON files directly on your PC to fetch your collection data.
- **Clean File Storage**: All local configuration, cache, and temporary files generated by this tool are strictly stored in `Documents/MS_BOT/`.

## 🇭🇰 繁體中文

**Marvel Snap Turbo** 是一款專為《Marvel Snap (漫威：瞬戰超能)》玩家打造的自動化與收藏管理工具。它可以幫你自動領取每日獎勵、監控網頁商店禮包，還能一鍵生成精美的卡片展覽館與好友分享！

### ✨ 核心功能
- **🚀 自動領取獎勵**：自動登入網頁並領取每日免費 100 點數。
- **🛒 禮包商店通知**：具備 8 天智慧過濾機制，自動將新禮包截圖並發送至 Discord。
- **📊 卡片收藏展覽**：同步本地遊戲數據，自動生成並排序卡片展覽館（依 Cost 優先、Power 次之雙重排序）。
- **📤 快速分享與導入**：一鍵生成專屬卡片庫代碼，或貼上好友的代碼即時檢視對方的收藏。
- **🌐 雙語介面切換**：支援英文與繁體中文介面一鍵切換。

### 📖 如何設定 Discord 通知功能
如果想要使用 Discord 接收領獎與商店禮包通知：
1. 點擊 **[邀請 MS Daily Store Alert Bot](https://discord.com/oauth2/authorize?client_id=1560327479711764603&permissions=117760&integration_type=0&scope=bot)** 將 Bot 加入至你的 Discord 伺服器。
2. 成功加入後，在該 Discord 伺服器任意頻道輸入 `!id`。
3. Bot 會透過私訊（DM）發送你的 **Discord 用戶 ID** 給你。
4. 複製該用戶 ID 並貼上至程式的設定欄位即可。

### 🔒 隱私與資料安全說明
- **零個人資料收集**：本程式**絕不會**獲取、記錄或上傳你的任何遊戲帳號、密碼或個人登入資料。
- **本地數據讀取**：程式僅會在你的電腦本機唯讀（Read-Only）讀取官方 Marvel Snap 的本地 JSON 數據檔以獲取卡片收藏。
- **檔案集中存放**：本程式產生的所有設定檔、快取與暫存文件均統一保留於你的電腦「`文件/MS_BOT/`」（`Documents/MS_BOT/`）資料夾中，不會隨意寫入其他系統目錄。
